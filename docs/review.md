## 1. 해 보는 법
- `npm run web` → http://localhost:5175 → [이어하기] 또는 [근무표] → **시험 · 봄 / 여름 / 가을 / 겨울**(이 순서로 열림).
- 선생님 모드(처음 번호 1234) → 학생을 고르면 아래에 기록이 나옵니다.
  - **단골과의 관계**: 숨은 신뢰(0~10)·단계·맞음/무난/어긋남 수·고른 대응 유형. 학생 화면에는 나오지 않습니다.
  - **판단 기록**의 커피 만들기 줄: 실수 · 드린 잔 · 다시 만들기 · 보기 · 손 기술마다 알맞음/해 본 수 · 단계 · 턴 방식.
  - [CSV로 저장]에도 대응 줄과 커피 만들기 줄이 함께 들어갑니다.
- 자동 플레이(개발자 도구 콘솔, `?debug`): `const { autoplay } = await import('/tools/autoplay.js'); await autoplay({ episode: 'm1_spring', respond: 'best', hint: true })`

## 2. 만든 것

### 2.1 한 잔의 마음: 대응 기회 10개 (PRD 8장)
| 에피소드 | 단골 | 기회 | 맞는 대응 |
| :--- | :--- | :--- | :--- |
| 봄 | 해순 할머니 | 1 · 우유 두 잔 | 두 번째 잔을 빈 의자 앞에 놓는다(기다림) |
| 여름 | 해순 할머니 | 2 · 그 의자의 손님 | 다른 자리를 관광객에게 조용히 권한다 |
| 여름 | 지안 | 1 · 아무거나요 | "오늘은 어떤 색이에요?"(묻기) |
| 여름 | 지안 | 2 · 시원한 거 아무거나 | 시원한 것 중에 어떤 색이 좋은지 묻는다 |
| 가을 | 해순 할머니 | 3 · 한 잔 남은 우유 | 한 잔만 데워 놓고 할머니 말을 기다린다 |

- 흐름: 장면 → 힌트 두 번 → 지은의 속마음(질문) → 카드(볼 때마다 순서를 섞음, [힌트 다시 보기]) → 반응 연출 → 반응 뒤 장면.
- 힌트 사다리: 1~2번째 기회는 그 사람의 대사 한 번 + 행동 한 번, 3번째는 행동 둘, 4~5번째는 시선 둘. `npm run validate`가 지킵니다.
- 반응 연출: 맞음 = 오래 바라봄(웃는 얼굴 + 하트 + 따뜻한 소리 + 글 "오래 바라본다") · 무난 = 미소 · 어긋남 = 작은 끄덕임 + "괜찮아요".
- 선택지마다 대응 유형(기다림·묻기·그대로·나서기)을 달아 선생님 화면에서 '사람에 맞게 바꾸는지' 봅니다.

### 2.2 커피 만들기 (PRD 6장, 미니게임 `brew`)
- 메뉴 셋: 따뜻한 우유(봄, 해순 할머니 두 잔) · 라테 + 아메리카노(여름, 관광객).
- 흐름: 주문 듣기 → 레시피 고르기(컵 → 바탕 → 더하기 → 온도) → 손 기술 → [드리기] → 손님 반응.
- 손 기술: 샷 내리기 · 우유 데우기 · 붓기(바리스타 단계는 거품 내기 + 붓기가 알맞으면 하트). ✅ [누르고 있기]를 누르는 동안 띠가 차오르고 '알맞아요' 칸에서 손을 뗍니다(2026-10-28, R-26). 띠에 글자(연해요 · 알맞아요 · 써요)가 있어 색만으로 알리지 않습니다.
- 감점·실패 화면 없음: 레시피가 틀리면 손님이 "이건 제가 주문한 게 아니네요." 하고 [다시 만들기]. 손 기술만 벗어나면 그 잔의 결과로 말하고 [다시 만들기]/[그대로 드리기].
- 단계 셋(쉬움 = 손 기술을 [보기]로 · 보통 · 바리스타), 설정의 '시간 제한'을 끄거나 자동 스캔이면 턴 방식([한 칸]씩 + [멈추기]). [보기]와 [레시피 수첩]은 언제든(수첩을 여는 동안 띠가 멈춤).
- 커피 솜씨는 단골 신뢰에 더하지 않습니다(원칙 7).
- 그림: 물건 시트가 오기 전까지 임시 그림(SVG). 시트가 오면 `assets/_src/objects/`에 두고 `npm run objects`.

### 13.2 고친 것 (같은 날 사용자 의견)
> 사용자: (참고 그림: 술집 · 초밥집 게임의 붓기 창, 캐릭터 옆 둥근 게이지) "이거랑 똑같아야 한다는 것은 아니다. 하지만, 지금은 게이지 bar가 따로 떨어져 있어서 어색하다. 게임안에 bar 시스템이 통합되어야 한다는 것은 이런 뜻이다. 현재 이미지들도 크기를 제대로 반영하지 않았다는 점도 인정하고, 수정하자. 중구난방이라서 정돈된 카페의 느낌이 아니다."

- **손 기술 = 확대 창**: 카운터가 어두워지고 그 위에 액자 하나가 뜹니다. 위 = 나무색 이름 띠(번호 · 손 기술 이름 · 하는 법 · 다시 듣기 · 레시피 수첩), 가운데 = 블렌더 한 컷, **그 오른쪽에 세로 띠**(아래부터 연해요 · 알맞아요 · 써요처럼, 바늘은 왼쪽 세모 + 가로 줄, 차오르는 색은 커피 · 데운 우유 · 우유 · 거품), 아래 = 지금 칸 · [누르고 있기] · [보기]. [시작!] 창도 액자 안에 뜹니다. 아래 쟁반의 가로 띠는 없앴습니다.
- **물건 크기 = 실제 비율**: 머그 높이 10cm를 잣대로(판 높이의 9.6%) 머신 36cm · 주전자 17cm · 우유병 22cm · 시럽병 24cm · 종이컵 12cm · 유리컵 13cm를 그림 파일의 가로 · 세로 비율로 셈. 받침 위의 컵도 같은 잣대(앞줄이라 1.1배).
- **정돈**: 서 있는 물건은 모두 카운터 안쪽의 같은 줄. 왼쪽 = 컵 셋(나무판 위), 가운데 앞 = 받침, 가운데 뒤 = 머신, 그 옆 = 주전자(뜨거운 물), 오른쪽 = 우유 · 시럽 · 얼음(나무판 위), 왼쪽 앞 = 레시피 수첩.
- **확인**: 자동 플레이 네 편 오류 0(레시피를 한 번 틀린 뒤 다시 만들기 포함).

검수 포인트 🙋

### 13.3 쟁반 · 모자람 · 넘침 연출 (같은 날 사용자 의견)
> 사용자: "트레이 크기를 2배 이상 키워야 할 것 같아. 그리고 게이지를 제대로 못 채우거나 넘쳤을 때의 에니메이션(주인공의 시무룩한 표정 포함)이 좀 더 화려하게 나오면 좋겠네. 효과음도 조금 더 극적이게."

- **모자라거나 넘쳤을 때**(손 기술 확대 창 안):
  - 창이 살짝 흔들림 · 벗어난 칸(넘침 = 위 칸, 모자람 = 아래 칸)이 네 번 깜빡임
  - 큰 글자 도장이 떨어지듯 찍힘: 넘침 = 주황 "앗, 써요!" · 모자람 = 푸른 회색 "앗, 미지근해요!"(손 기술마다 띠 글자 그대로)

  - 다음 단계까지 2.3초(알맞을 때는 1.1초) 보여 줌
- **효과음**(산 팩 Anime Comedy에서 새로 자름): 넘침 = 철퍽(`spill`) → 깜짝(`miss_high`, AC_Surprised_01v1) → 식은땀(`sweat`, AC_Funny_Sweat_01v1) · 모자람 = 쪼그라듦(`miss_low`, AC_Shrink_01v1) → 축 처지는 떨림(`miss_sulk`, AC_Depressed_Tremolo). 꾸중이 아닌 장난스러운 과장입니다(감점 · 실패 화면 없음, 원칙 2).

### 13.4 실패했을 때 [다시 하기] (같은 날 사용자 의견)
> 사용자: "실패했을 때, 드리기 말고 다시 하기 버튼이 있으면 좋겠다. 스스로 리트라이를 선택하도록 하자."

- 손 기술이 모자라거나 넘치면 연출(도장 · 시무룩한 지은 · 효과음)이 나온 뒤 **저절로 넘어가지 않고** 확대 창 아래에서 학생이 고릅니다: "다시 해 볼까요? 이대로 해도 괜찮아요."
  - **[다시 하기]**(초록, 처음 초점): 도장과 얼굴을 걷고 띠와 장면을 처음으로 되돌린 뒤, 그 손 기술만 바로 다시 합니다(앞 단계는 그대로, 시작 창 없이, [보기]는 그대로 있음). 몇 번이든 할 수 있습니다.
  - **[이대로 하기]**: 그 잔의 결과로 다음 단계로 갑니다. 드리면 지금처럼 손님이 결과를 말하고("조금 연하네요.") [다시 만들기] / [그대로 드리기]를 고릅니다.

### 13.5 물건 자리 · 온도 고르기 창 (같은 날 사용자 의견)
> 사용자: (작업대 화면) "테이블보다 위쪽에 물건들이 다 놓여있네. 위치를 다시 잡아야겠다." · "따뜻하게 버튼을 누르면 팝업이 뜨면서 따뜻하게와 차갑게를 고를 수 있게 해줘야 한다."

- **원인**: 물건 단추의 아래 끝이 물건 바닥이 아니라 그 밑에 붙은 이름표의 아래 끝이었습니다. 그래서 물건이 이름표 높이만큼 떠서, 바닥이 카운터 뒤 끝선(벽과 만나는 줄)에 걸려 보였습니다.
- **물건 자리**: 이름표를 물건 바닥 아래에 매달고, 바닥을 카운터 판 위로 내렸습니다. 판은 그림 아래에서 12.3%(앞 끝) ~ 32.4%(뒤 끝)입니다. 서 있는 물건은 25%(뒤 끝에서 판 깊이의 3분의 1쯤 앞), 받침 · 레시피 수첩은 17.5%(손 띠 바로 위)에 둡니다. 크기는 그대로입니다(I-24).
- **온도 고르기 창**: 손 띠의 [따뜻하게] 칸을 누르면 그 바로 위에 작은 창이 뜹니다. "따뜻하게 할까요, 차갑게 할까요?" + [따뜻하게] · [차갑게](지금 고른 것은 초록 테두리 + 체크).
  - 고르면 칸 글자와 그림이 바뀌고(차갑게 = 얼음), 받침 위 작은 그림과 카운터의 얼음통에도 표시가 납니다.
  - 창 밖을 누르거나 Esc를 누르면 바꾸지 않고 닫습니다. 키보드 · 스캔으로도 고를 수 있습니다.
  - 카운터의 얼음통을 눌러도 그대로 차갑게 됩니다.
- **확인**: 1920×1080 화면으로 물건 자리 · 창 열기 · 차갑게 · Esc · 창 밖 누르기 · 따뜻하게로 되돌리기 · 키보드(Tab → Enter). 네 편 자동 플레이 오류 0.

### 13.6 받침 · 머신 자리 (같은 날 사용자 의견)

### 13.7 우유 데우기 컷에 우유 (같은 날 사용자 의견)

> 사용자: "테이크아웃용 플라스틱 컵도 있어야 한다. 플라스틱컵은 좀 길쭉한 것으로(차가운 음료 테이크 아웃 용) 그것도 만들어줘. (길쭉한 컵) 마찬가지로 테이크아웃용 종이컵(따뜻한 음료용)도 제작이 필요하면 블랜더로 제작부탁한다. 딸기우유, 녹타라떼, 코코아는 음료 색만 바꾼 장면 만들어줘."

- **종이컵**(따뜻한 음료 포장): 크라프트 슬리브를 끼운 흰 종이컵. 속이 안 보여서 머그처럼 위에서 내려다봅니다. 물 붓기(아메리카노) · 우유 붓기 · 라테(하트도) · 녹차라테 · 코코아.
- **플라스틱 컵**(차가운 음료 포장): 높이 15cm의 길쭉한 투명 컵. 유리컵처럼 앞에서 봅니다. 얼음이 한 국자씩 24개까지 담기고, 찬물(아이스 아메리카노) · 찬 우유 · 아이스 라테 · 딸기우유 · 아이스 녹차라테 · 아이스 코코아.
- **음료 색**: 딸기우유(분홍) · 녹차라테(연두) · 코코아(밀크 초콜릿 색)는 붓기 장면에서 색만 바꿨습니다. 바탕(딸기청 · 말차 · 코코아)이 깔린 컵에 우유를 부을수록 그 색이 됩니다. 머그 · 유리컵에도 있습니다.
- 컷 이름은 이야기 브랜치의 작업대가 정해 둔 규칙과 같아서, 그 브랜치에 합치면 코드를 고치지 않아도 바로 나옵니다(13.11의 I-28 · I-29 답).

검수 포인트 🙋
- **I-30** 종이컵: 갈색 슬리브(손 데지 않게 끼우는 띠)를 끼웠고 무늬 · 글자는 없습니다(간판처럼 비워 둠). 뚜껑은 붓는 중이라 없습니다.
- **I-31** 플라스틱 컵: 유리컵처럼 밝은 컵받침 위에 두었습니다(투명한 바닥에 나무색이 비쳐 커피처럼 보여서). 포장 컵에 받침이 어색하면 빼겠습니다.
- **I-32** 음료 색: 딸기우유 분홍 · 녹차라테 연두 · 코코아 밀크 초콜릿 색이 괜찮은지. 따뜻한 녹차라테 · 코코아에는 끝 무렵 가운데에 우유 거품 동그라미가 생깁니다.
