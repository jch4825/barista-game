## 0. 한눈에
- 커피 한 잔은 네 단계입니다. **① 주문 듣기 → ② 레시피 고르기 → ③ 손 동작 → ④ 내기**.
  - ① 주문 듣기와 ② 레시피 고르기는 지금처럼 합니다(컵·재료·온도를 고르는 커피토크 방식).
  - ③ 손 동작은 레시피마다 다른 동작 **4~6개**를 합니다(✅ Q-R3).
- 시험판의 ③은 '띠가 칸에 오면 멈추기' 한 가지뿐이라 단조로웠습니다. 그래서 실제 바리스타 동작에 맞춘 **동작 8가지**(2장)로 나눕니다.
  - **누르고 있다가 떼기**: 샷·스팀·물 (✅ 1단계로 먼저 바꿈)
  - **원 그리기**: 젓기·드립·손 그라인더
  - **곡선 따라 긋기**: 라테아트·포터필터 끼우기
  - **박자 맞춰 누르기**: 거품·얼음·시럽 펌프
  - 그 밖: 쓸기·기울여 붓기·기다렸다 누르기·순서대로 누르기
- 메뉴는 이야기 메뉴 14개 + 자유 영업 메뉴입니다(3장). 계절마다 새 동작이 열립니다(4장). 겨울 정전 밤의 핸드드립은 '기다림'을 손으로 하는 큰 동작입니다(✅ Q-R6).
- 연출은 블렌더로 미리 렌더한 사실적인 3D 그림과 프레임을 2D로 넣습니다(✅ Q-R7, 6장). 게임 안에서 실시간 3D는 쓰지 않습니다.

## 1. 지키는 것
- **손으로 만드는 커피**(원칙 7): 정답 고르기가 아니라 손으로 하는 일입니다. 실수는 그 잔의 결과(연함·씀·미지근함·넘침·기운 하트)로 보이고, 그 동작만 다시 하거나 그대로 드리면 됩니다. 감점·실패 화면은 없습니다.
- **솜씨는 신뢰에 더하지 않음**(원칙 7): 손 동작을 잘해도 못해도 단골 신뢰는 그대로입니다. 기록은 선생님 화면에만 남습니다.
- **세 가지 길**(원칙 11): 모든 동작은 아래 셋으로 할 수 있어야 합니다.
  - **직접**: 손가락·마우스로 긋기·누르기.
  - **한 단추**: Space 키나 스위치 하나로, 누르기·떼기만으로 끝까지 할 수 있습니다. 곡선 긋기도 한 단추로 합니다(점이 길을 따라 저절로 가고, 표시 칸에 올 때 누르기).
  - **[보기]**: 저절로 알맞게 해 주고, 기록에는 '보기'로 남습니다.
- **연타 없음**(✅ Q-R2): 빠르게 여러 번 누르기는 손이 불편한 학생에게 어려워 쓰지 않습니다. 대신 '누르고 있기'나 '박자 맞춰 한 번씩'을 씁니다.
- **시간 압박 없음**: 동작 안의 타이밍은 '알맞은 칸'일 뿐입니다. 이야기에서는 시간 제한 막대가 없습니다(자유 영업에서만 설정으로). 설정의 '시간 제한 끄기'와 자동 스캔이면 턴 방식(한 칸씩)이 됩니다.
- **색만으로 알리지 않음**: 칸마다 글자(연해요·알맞아요·써요)가 있고, 알맞으면 부드러운 '딩' 소리가 납니다. 무서운 소리·번쩍임·흔들림은 없습니다. 차분 모드에서는 그라인더·스팀 소리를 줄입니다.
- **안전**: 스팀·뜨거운 물 동작 앞에 한 줄 안전 안내를 합니다(지금처럼). 게임 속에서 다치는 장면은 없습니다.
- **타사 IP**: 커피토크에서는 '재료를 골라 만드는 방식'만 가져옵니다. 리듬 게임·QTE는 장르의 흔한 조작만 쓰고, 특정 게임의 화면·판정 글자·소리는 쓰지 않습니다.

- **G(기다렸다 누르기)**: 학생이 '기다림'을 손으로 해 보는 동작입니다. 해순 할머니의 '기다림', 사장님의 "맛은 시간이 만듭니다"(숨은 장면 3), 지은의 '느리고 정확한 손'과 이어집니다.
- **동작 하나의 흐름** (공통):
  1. 그림 + 한 줄 안내 + 읽어 주기. [보기] 단추도 함께 있음
  2. 동작
  3. 판정 글자 + 소리
  4. 결과가 잔에 바로 보임
  5. 벗어났으면 [이 동작 다시] / [그대로 가기]
- **판정 칸의 넓이**: 쉬움은 넓게, 보통은 지금 너비, 바리스타는 좁게. 박자(D)의 빠르기도 단계마다 다릅니다.
- 🙋 **'딱 좋아요!'**(Q-R4): 판정이 칸으로 나뉘는 동작(A·B·D·E·F·G)은 '알맞아요' 칸 가운데에 '딱 좋아요' 칸을 둡니다. 반짝임과 소리만 다르고, 음료·손님 말·신뢰는 '알맞아요'와 같습니다. 숫자 점수는 없습니다.

## 3. 메뉴별 레시피 카드 ✅ Q-R1 (동작 순서는 🙋)
**한 잔 4~6동작**(✅ Q-R3). 🙋 보통은 4~5동작, 바리스타는 같거나 1~2동작 더(6까지)하고 판정 칸이 좁습니다. 쉬움은 같은 순서를 모두 [보기]로 합니다.

**자주 나오는 묶음**:
- **샷**: 보통 = 탬핑(E) → 추출(A), 갈기는 저절로 · 아메리카노처럼 샷이 중심인 잔은 갈기(A)부터. 바리스타의 아메리카노만 원두 고르기(E)·포터필터 끼우기(C)까지 다섯 동작을 모두 합니다.
- **우유**: 데우기(A) → 붓기(F). 바리스타는 거품(D)과 라테아트(C)를 더합니다.

## 5. 바꾸는 순서
- **1단계** ✅ 끝냄(2026-10-28, Q-R8): 손 기술 넷(`extract`·`steam`·`foam`·`pour`)을 **A(누르고 있다가 떼기)**로 바꿈. 메뉴 데이터는 그대로이고 조작만 바뀜. 화면: `docs/design/brew_hold_release.jpg`.
  - 실시간: 손 그림 단추 **[누르고 있기]**. 누르는 동안만 띠가 차오르고, 손을 떼면 그 칸으로 정합니다. 끝까지 누르고 있으면 높은 칸(써요·뜨거워요·넘쳐요)이 됩니다.
  - 아주 짧게 누르면(보통 약 0.3초 안, 넉넉히는 0.6초) 실수로 톡 누른 것으로 보고 처음부터: "조금 더 꾹 누르고 있어요."
  - 자판: 단추에 초점을 두고 스페이스·엔터를 누르고 있다가 뗍니다. 터치가 끊기거나 초점이 나가면 정하지 않고 그 자리에서 멈춥니다(다시 누르면 이어서 참).
  - 턴 방식(시간 제한 끄기·자동 스캔): 오래 누르기가 어려운 학생을 위해 그대로 [한 칸]씩 + [멈추기].
  - 🙋 '딱 좋아요!'(Q-R4): 알맞아요 칸 가운데 36%에서 떼면 나옵니다. 띠에 위·아래 테로 그 자리를 보여 주고, 맞히면 테가 금색으로 바뀌고 글자 띠에 반짝임이 한 번 지나갑니다(차분 모드·움직임 줄이기에서는 반짝임 없음). 턴 방식은 가운데에 가장 가까운 눈금 하나. [보기]로 한 것은 해당 없음. 선생님 화면 비고에 "알맞음 2/3(딱 좋아요 1)"처럼 남습니다.
  - 칸 글자는 바늘 위에 보입니다(가운데에서 멈추면 바늘이 '알맞아요'를 가리던 것을 고침).
  - 고친 파일: `js/game/minigames/brew.js`(runSkill·gate·읽어 줄 문장), `js/data/menu.js`(`howto` 누르고 떼기 · `howtoTurn` 턴 방식), `css/brew.css`·`css/skin-sea.css`(누른 모양·'딱 좋아요' 테·고대비), `js/screens/teacher.js`(비고).
  - 아직: 시험판의 잔은 손 기술 1~4개(아메리카노 1 · 따뜻한 우유 2 · 라테 3~4)라 '한 잔 4~6동작'은 2단계부터 맞춥니다.
- **2단계**: 동작 틀 하나에 B~H를 차례로 더합니다. 직접 · 한 단추 · 보기 · 턴 방식을 모든 동작이 같은 틀로 받습니다(지금의 `arcade.js` 고리를 이어 씀). 데이터는 레시피마다 동작 순서를 적는 꼴입니다. 🙋 먼저 E(탬핑·톡톡)와 F(붓기)를 넣어 봄 메뉴 셋을 4동작으로 맞춥니다.
  ```
  latte: { …, steps: [
    { act: 'swipe', skill: 'tamp', dir: 'down' },   // E
    { act: 'hold', skill: 'extract' },              // A
    { act: 'hold', skill: 'steam' },                // A
    { act: 'beats', skill: 'foam', n: 3 },          // D (바리스타)
    { act: 'tilt', skill: 'pour' },                 // F
    { act: 'path', skill: 'art', shape: 'heart' },  // C (바리스타)
  ] }
  ```
- **3단계**: 메뉴를 계절 순서대로 더하고(3장), 레시피 수첩·도감을 늘립니다. `npm run validate`가 메뉴마다 동작이 4~6개인지, 그림·음성 문장이 다 있는지 검사합니다.

### 6.9 피처에 우유 붓기 · 피처 톡톡 컷 (✅ 2026-10-31 게임에 넣음, 사용자 "우유 붇는 에니메이션이 없네. 거품도 에니메이션이 없네.")
- 첫 우유 만들기(따뜻한 우유: 피처에 우유 붓기 → 우유 데우기 → 피처 톡톡 → 붓기)에서 두 손 동작만 물건 그림이라 움직임이 없었습니다. 손 동작 id 와 같은 이름의 컷이라 코드 없이 나옵니다.
- **`milk_in`(피처에 우유 붓기, 누르고 떼기)**: 작업대 위 빈 스팀 피처(주둥이 왼쪽)에 왼쪽에서 기운 유리 우유병(카운터의 우유병과 같은 꼴, 뚜껑 연 채)으로 우유를 붓습니다. 오른쪽 앞 위(약 56°)에서 피처 속을 내려다봅니다.

## 7. 학생에게 보이는 말 (쉬운 한국어)
- 동작 안내는 한 줄입니다.
  - 지금 쓰는 말(A): "[누르고 있기]를 꾹 누르면 샷이 나와요. 알맞아요 칸에서 손을 떼요." · 턴 방식은 "띠가 알맞아요 칸에 오면 [멈추기]를 눌러요."
  - 짧게 눌렀을 때: "조금 더 꾹 누르고 있어요." · 가운데에서 뗐을 때: "딱 좋아요!"
  - 앞으로의 예: "컵 위에 동그라미를 세 번 그려요." · "점선을 따라 하트를 그려요." · "동그라미가 겹칠 때 눌러요."
- 판정 글자는 칸 글자와 같은 말을 씁니다(알맞아요 · 조금 빨라요 · 조금 늦어요). 숫자 점수·순위·'실패'는 없습니다.
